# Berlin radio redesign

Major changes:

- Replaced generic procedural city macro-layout with a recognizable Berlin-first spatial skeleton.
- Added Spree, parks, districts/areas, major hubs and landmarks.
- Removed direct rider assignment from the gameplay model.
- Added limited radio call-outs as the player's primary action.
- Added autonomous rider task selection.
- Added rider personalities, experience levels, decision noise and decision explanations.
- Added likely-choice prediction and map attention lines.
- Made normal job type generation district-independent.
- Added landmark/district/reliability shift goals.
- Reworked onboarding and persistent instruction hierarchy.
- Reworked visual language for uncalled, called and claimed jobs.
- Expanded tests around geography, routing, radio limits and autonomy.
