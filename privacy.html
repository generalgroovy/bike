Send It — Privacy

Send It is a browser game. Core simulation data stays in your browser and does not require an account.

Local browser storage

The game stores local preferences such as UI density, rail state, best score and, if you choose to enable it, your Google Maps JavaScript API key. The key is stored only in your browser localStorage and is not committed to this repository or sent to a Send It server.

Optional Google Maps mode

If you enable Google Maps, your browser loads Google Maps JavaScript API resources directly from Google. Google may process technical information such as IP address, browser information, referrer/origin and map requests under the Google Privacy Policy and Google Maps Platform terms.

Send It does not copy, cache or store Google map content. The Google basemap is rendered live by Google Maps and can be disabled at any time with the G control.

No sale of data

Send It has no advertising system and does not sell personal information.
